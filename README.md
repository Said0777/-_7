# DIO App — Flutter приложение с API

Приложение загружает список постов с публичного API [JSONPlaceholder](https://jsonplaceholder.typicode.com/) с помощью библиотеки **DIO** и отображает их на главном экране.

## Функциональность

- GET-запрос к `https://jsonplaceholder.typicode.com/posts` через DIO
- Парсинг JSON-ответа в объекты `Post`
- Список постов с карточками на главном экране
- Детальный просмотр каждого поста
- Обработка ошибок сети (нет интернета, таймаут, ошибка сервера)
- Pull-to-refresh для обновления списка
- Поддержка светлой и тёмной темы

## Структура проекта

```
lib/
├── main.dart                  # Точка входа
├── models/
│   └── post.dart              # Модель поста с fromJson()
├── services/
│   └── api_service.dart       # DIO-клиент и запросы к API
├── screens/
│   ├── home_screen.dart       # Главный экран со списком постов
│   └── post_detail_screen.dart# Экран детального просмотра
└── widgets/
    └── post_card.dart         # Карточка поста
```

## Запуск

```bash
# 1. Установить зависимости
flutter pub get

# 2. Запустить приложение
flutter run
```

Никаких дополнительных настроек не требуется — API публичный и работает без ключей.

## Зависимости

```yaml
dio: ^5.4.0  # HTTP-клиент
```
